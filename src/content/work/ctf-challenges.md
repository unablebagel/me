A collection of capture-the-flag challenges I've designed and solved, primarily focusing on finding flags hidden inside intentionally vulnerable applications.

## Covered Topics
- **Web Exploitation:** SQL Injection, Cross-Site Scripting (XSS), Server-Side Request Forgery (SSRF), Command Injection
- **Cryptography:** RSA weaknesses, AES block cipher mode attacks, Hash length extension attacks
- **Reverse Engineering:** x86/x64 assembly, buffer overflows, format string vulnerabilities
