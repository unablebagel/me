## Technical Implementation

### Constraint Modeling

- **Normal Mode:** Uses a standard BFS frontier to ensure orthogonal adjacency. Each selection expands the "frontier" of valid seats.
- **Divider Mode:** Restricts horizontal expansion across user-defined lane dividers. Logic: `if (hasDividerBetween(a, b)) skip;`
- **Safe Distancing:** Confirming a booking triggers a secondary traversal to lock all surrounding neighbors (Front, Back, Left, Right).

### Complexity

- **O(R × C) Time**
- **O(R × C) Space**

Validation re-runs on every click, ensuring zero-latency feedback for the user.

// Standard Adjacency Logic
function getNeighbors(r, c) {
  return [[r-1,c],[r+1,c],[r,c-1],[r,c+1]]
    .filter(([nr, nc]) => isInBounds(nr, nc));
}
